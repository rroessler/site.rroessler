This website is an [open-source](https://github.com/rroessler/rroessler.io) static [Next.js](https://nextjs.org/) application running on [GitHub Pages](https://docs.github.com/en/pages). For those interested, the simplified tech-stack that I am using is:

- [Fumadocs](https://www.fumadocs.dev/)
- [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

I chose to write my website this way as it allowed me to deploy for free, use [MDX](https://mdxjs.com/) for rendering my posts/projects, and for the creation of a performant and well-optimized static site. Alongside these items, I also use [Bun](https://bun.com/) and [TypeScript](https://www.typescriptlang.org/) for the sites development.
